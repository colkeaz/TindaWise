# App screenshots used in the deck

Captured from the signed v1.0.0 APK running on an Android emulator (1080x1920) with fictional data. No SMS was sent: the reminder is a draft the owner must send.

- `confirm_58.png` - owner confirmation card, 2 x Canton PHP 16 + 1 x Sardines PHP 26 = PHP 58.
- `direct_peso_50.png` - direct-peso entry, PHP 50.
- `sms_banner.png` - saved entry, balance PHP 58, drafted reply text.

The screenshots are cropped to the confirmation area so the app's in-UI 'RA 10173' badge is not presented as a compliance claim.
